

# Restaurant Recommendation Program

Welcome to our Restaurant Recommendation Program! This program helps users discover delicious dining options in the Greensboro NC area based on cuisine preferences, ratings, and price range.

## Table of Contents

- [Introduction](#introduction)
- [Features](#features)
- [Installation](#installation)
- [Usage](#usage)
- [License](#license)

## Introduction

Choosing a restaurant for your next meal can be a daunting task, especially with so many options available. Our Restaurant Recommendation Program aims to simplify this process by providing personalized recommendations tailored to your preferences. Whether you're craving Italian pasta, Japanese sushi, or American barbecue, our program has got you covered.

## Features

- **Cuisine Selection**: Choose from a wide variety of cuisines including Italian, Japanese, Mexican, and more.
- **Rating Filter**: Filter restaurants based on user ratings to find highly recommended dining spots.
- **Price Range**: Specify your budget with our price range filter to discover restaurants that fit your budget.
- **Detailed Information**: Get detailed information about each recommended restaurant including its name, rating, price range, type of food, and address.

## Installation

1. Clone the repository to your local machine:
   ```
   git clone https://github.com/yourusername/restaurant-recommendation-program.git
   ```

2. Navigate to the project directory:
   ```
   cd restaurant-recommendation-program
   ```

3. Install any necessary dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage

1. Run the program:
   ```
   python restaurant_recommendation.py
   ```

2. Follow the prompts to select your preferred cuisine, rating filter, and price range.

3. Receive personalized restaurant recommendations based on your preferences.

4. Enjoy your dining experience at the recommended restaurant!
